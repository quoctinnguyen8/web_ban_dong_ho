# Dự Án Vibe Coding - Web Bán Đồng Hồ

Dự án này được xây dựng hoàn toàn bằng kỹ thuật vibe code với nội dung prompt tối thiểu.

Mục tiêu: Tạo repo tham khảo đơn giản cho các dự án sử dụng AI vibe code.

- `.github/copilot-instructions.md`: Mô tả cơ bản về dự án và một số chỉ dẫn cho Copilot.
- `AGENTS.md`: Các yêu cầu bắt buộc đối với các agent tham gia dự án.
- `.agents/`: Thư mục chứa các agent thực hiện các nhiệm vụ cụ thể, bao gồm:
    - `db-designer`: Thiết kế cơ sở dữ liệu theo quy tắc của người dùng.
    - `manual-tester`: Thực hiện kiểm thử thủ công theo kịch bản đã xác định.
